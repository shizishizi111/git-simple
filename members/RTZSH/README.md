## Git 初次实验总结

1. `git add`：用来选中改动的文件并放到暂存区域，标记这些文件准备提交。这一步仅做登记，不会生成版本快照。
2. `git commit`：将暂存区内所有改动打包，在本地仓库生成一个新版本，备注信息用来记录本次做了什么修改，方便后续查看历史变更。
3. 本次实验 `git restore notes.md`：撤销 notes.md 文件里还没提交的改动，将文件还原到上一次提交的状态，临时写的内容会直接消失。
4. `commit` 和 `push` 的不同：`commit` 保存版本只存在你本机；`push` 是把本地已经提交好的版本上传到 GitHub 远程仓库，团队成员能够拉取、查看这份文件。
