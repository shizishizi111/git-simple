1.  git status ：查看当前仓库状态，可以看到哪些文件被修改、哪些已经进入暂存区，方便确认接下来要操作的文件。
​
2.  git log ：查看提交历史记录，能够看到每一次 commit 的作者、时间、备注信息，用来回溯项目各个版本。
​
3.  git pull ：从远程仓库拉取最新代码到本地，同步团队其他人提交的改动，在开始写代码之前经常执行。
​
4.  git clone ：把 GitHub 上面的远程仓库完整下载到自己电脑本地，初始化得到一个完整的 Git 项目。
​
5.  git diff ：对比文件改动，查看修改前后具体哪些行代码发生了变化，还没有 add 之前可以用来检查改动。
