# 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：把我准备提交的文件或修改放到暂存区，让 Git 知道这次提交具体要包含哪些内容。它只是准备提交，还没有真正生成一个版本
2. `git commit` 的作用是：把暂存区里的内容保存成一个正式的版本，并记录提交说明，以后可以通过提交记录查看项目的变化
3. 本次实验中 `git restore notes.md` 的作用是：放弃 `notes.md` 中还没有提交的临时修改，把文件恢复成上一次提交时的内容，所以后来追加的那句话就消失了
4. `commit` 与 `push` 的区别是：`commit` 是把修改保存到自己电脑上的本地 Git 仓库中；`push` 是把本地已经提交的内容上传到远程仓库，让 GitHub 上的其他人能够看到
